# Epics & Heroic Sagas

## Actual text policy

Unlike the earlier placeholder manifests, this collection contains **real story text** in the repository.

There are 14 story episodes, and each episode contains:
- English
- Hindi
- Arabic
- Urdu

The four versions are semantically aligned to the same narrative.

## Text type

These are **original faithful retellings** of traditional epic narratives. They are not copied modern translations. This lets the repository store usable multilingual story content while avoiding accidental redistribution of a later copyrighted translation.

A retelling is not presented as the canonical Sanskrit, Greek, Old English, Persian, Finnish or Irish source text.

## Editorial rule

Human review is still required before publication, especially for sensitive religious interpretation and stories involving war or death.
