# Festival Stories — Geography and Tradition Coverage

| Festival / story | Main setting | Narrative layer |
|---|---|---|
| Diwali — Rama Returns | North India / Ayodhya tradition | Ramayana-linked tradition |
| Holi — Prahlada and Holika | India | Hindu traditional legend |
| Janmashtami — Krishna's Birth | Mathura / Gokul tradition | Scriptural and devotional tradition |
| Ganesh Chaturthi — Ganesha | India / Maharashtra | Puranic tradition + modern public history |
| Onam — Mahabali | Kerala | Kerala traditional legend |
| Vaisakhi — Khalsa | Anandpur Sahib, Punjab | Documented Sikh history + tradition |
| Vesak / Buddha Purnima | South and Southeast Asia | Buddhist festival tradition |
| Eid al-Fitr | Muslim communities worldwide | Living religious observance |
| Christmas — Nativity | Bethlehem / Christian world | Gospel narrative + living tradition |
| Easter — Empty Tomb | Jerusalem / Christian world | Gospel narrative + Christian belief |
| Hanukkah — Temple Rededication | Jerusalem / Judea | Historical event + rabbinic tradition |
| Passover — Exodus | Egypt / ancient Israel narrative | Torah narrative + Jewish tradition |
| Nowruz | Iran and wider Persianate world | Living cultural tradition + legend |

Future expansion should add regional versions of festivals rather than collapsing different communities into one canonical story. Dates should be generated dynamically from the relevant religious or traditional calendar rather than hard-coded into story text.
