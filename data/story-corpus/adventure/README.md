# Adventure & Quest Corpus

This collection contains actual story text rather than placeholders.

## Four-language rule

Every story is stored in:
- English
- Hindi
- Arabic
- Urdu

The four versions are aligned to the same underlying narrative.

## Story type

The text is marked ORIGINAL_FAITHFUL_RETELLING. These are repository-authored retellings of traditional or public-domain literary narratives, not copied modern translations.

## Meaning preservation

Every translation preserves the same plot events, relationships, sequence, major objects, uncertainty and outcome. It is not a summary.

## Source lineage

The narratives were selected because the underlying classic works/traditions are old and have public-domain historical editions available from sources such as Project Gutenberg. For example, Project Gutenberg lists Treasure Island, The Prisoner of Zenda, The Swiss Family Robinson, Around the World in Eighty Days, and The Adventures of Tom Sawyer as public domain in the USA. Wider commercial distribution still requires jurisdiction review.
